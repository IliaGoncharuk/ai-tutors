# 0003. Локальная веб-лаборатория для Дня 3

- Статус: принято
- Дата: 2026-09-03

## Контекст

Третий челлендж требует получить четыре решения одной задачи через API и
сравнить их. Результат должен быть проверяемым, наглядным для короткой
демонстрации и не требовать постоянной инфраструктуры.

## Рассмотренные варианты

1. Локальный веб-интерфейс с четырьмя карточками и экспортом отчёта. Хорошо
   показывает ответы рядом и позволяет повторять эксперимент, но требует
   браузерной клиент-серверной части.
2. Kotlin Desktop по образцу Дня 2. Сохраняет знакомый desktop-стек, однако
   четыре длинных решения и раскрываемые промпты перегружают компактное окно.
3. TypeScript CLI. Даёт самый маленький код, но хуже подходит для визуального
   сравнения и демонстрации результата.

## Решение

Выбран локальный одностраничный веб-интерфейс на React/Vinext с серверным
маршрутом Responses API. Фиксированная задача имеет однозначный численный
эталон, поэтому точность можно оценить локально, не поручая проверку второй
модели. Тексты и метрики остаются видны для содержательного сравнения, а экспорт
формирует требуемый Markdown-результат.

API-ключ читается из `OPENAI_API_KEY` только серверным runtime. Приложение не
публикуется и не хранит ответы на сервере. Один полный запуск содержит пять
платных запросов; действие всегда инициирует пользователь.

## Последствия

- Эксперимент легко повторить на трёх доступных в интерфейсе моделях.
- Сравнение честно допускает ничью и частичный результат при ошибке ветки.
- Проверка численного итога воспроизводима, но не является полной оценкой
  качества рассуждения и не позволяет обобщать один запуск на все задачи.
- Для демонстрационного результата пользователь должен выполнить реальный
  запуск со своим API-балансом и скачать отчёт.
