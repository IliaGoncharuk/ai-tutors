# Решение 0010: локальный сайт с явными слоями памяти

- Статус: принято 2026-09-20.
- Основание: пользователь утвердил замену Дня 11 локальным сайтом, удаление
  прежнего решения без архива и последовательное выполнение дней 11–15
  в самостоятельных каталогах с реальными API-проверками.
- Это решение заменяет прежний выбор CLI для Дня 11.

## Контекст и варианты

Нужно видеть одновременно вопрос, ответ и сведения, повлиявшие на ответ.
Каждое учебное задание должно запускаться самостоятельно и объяснять себя
без знакомства с перепиской или исходниками предыдущего дня.

Рассмотрены два варианта. Единое приложение с переключателем дней уменьшает
дублирование кода, но смешивает учебные результаты и связывает версии общей
реализацией. Отдельные локальные сайты требуют повторять часть основы,
зато каждый каталог содержит законченный результат своего дня.
Выбран второй вариант; прежний CLI не сохраняется как параллельное решение.

## Принятое устройство

День 11 находится в `challenges/day-11-memory-layers`. React и TypeScript
отвечают за интерфейс, Vite — за локальную разработку и сборку,
Node.js — за хранение и обращения к OpenAI. Исполняемых импортов между
заданиями нет. Одна команда запускает сервер и интерфейс на `localhost:3011`.

Текущий диалог, рабочие сведения задачи и долговременные записи хранятся
в разных JSON-файлах. Журнал и выбор активных сущностей отделены от данных
памяти. Все документы одной версии публикуются через указатель `CURRENT.json`,
чтобы восстановление получало согласованный снимок. Личные данные по умолчанию
находятся в домашнем каталоге пользователя вне Git.

Перенос данных в рабочую и долговременную память выполняет пользователь
отдельным действием. Автоматическое извлечение фактов моделью здесь не требуется:
предмет задания — видимые правила записи и влияние слоёв. Обычная переписка
пополняет только краткосрочную память из последних шести сообщений.

Для проверки влияния одного слоя сравнение делает четыре запроса из одного
снимка и не добавляет ответы в диалог. Иначе ранний ответ мог бы перенести
исключённый позднее факт через краткосрочную память и исказить результат.

Настоящие ответы получаются через Responses API с `gpt-5.6-luna`. Явно
включаемая симуляция помогает изучать интерфейс без вызова модели.
Отдельная маркировка сохраняет различие между демонстрацией механизма
и экспериментальным наблюдением. Ключ доступен только серверу.

## Последствия

Интерфейс делает сохранение и состав запроса обозримыми; самостоятельный
каталог облегчает запуск и сравнение учебных этапов. Цена выбора — повторение
части кода в следующих днях и больше файлов, чем у прежнего CLI.
JSON подходит для локальной учебной лаборатории, но не превращает её
в многопользовательский сервис или зашифрованное хранилище.

Корректная память не гарантирует правильного использования факта моделью.
Поэтому проверяются отдельно файлы, контекст и ответы, а результаты предыдущей
реализации не переносятся на новую. Каноническое поведение и критерии приёмки —
в [спецификации](../features/day-11-memory-layers.md).
