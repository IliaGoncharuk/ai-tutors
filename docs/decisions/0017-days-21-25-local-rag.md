# 0017. Пять самостоятельных локальных RAG-лабораторий

Принято пользователем 2026-10-05: выполнить дни 21–25 последовательно;
реальные API-проверки всей серии разрешены в общем бюджете до $1.

Каждый день — самостоятельный сайт React/TypeScript/Node.js в своей папке,
с портом 3021–3025 и без исполняемых импортов между заданиями. Следующее
задание развивается из проверенной копии предыдущего. Альтернатива — общая
библиотека — уменьшила бы повторение, но связала бы уже завершённые задания.

Один зафиксированный корпус: README дней 1–20. Разделы с точным заголовком
`## Исходное задание` удалены до следующего раздела; старые README с другими
заголовками сохранены целиком.
Снимки содержатся в каждом задании; вопросы и ожидаемые ответы в индекс не
входят. Markdown нормализован в LF. Мера объёма — 500 слов на условную страницу,
а не страницы PDF. Импорт PDF и OCR в эту серию не входят.

SQLite хранит индекс, метаданные, историю и состояние. Поиск — локальное
косинусное сходство с векторами `text-embedding-3-small`, 512 измерений.
Генерация — `gpt-5.6-luna` через Responses API. Тексты для эмбеддингов и
контекст ответа отправляются в OpenAI; ключ берётся только из окружения.

Рабочий каталог по умолчанию — `~/.ai-tutors/rag-campaign`; `RAG_DATA_DIR`
может указать другой локальный каталог. В проверках используется исключённый
из Git `.local-rag`. У каждого дня своя база; общий `campaign.sqlite` хранит
кеш эмбеддингов и журнал бюджета с атомарными резервами, сохраняемыми при
неизвестном результате запроса. Повторные запросы автоматически не выполняются.
Расход рассчитывается по usage и консервативному тарифу; это не сверка счёта.

Публичные артефакты содержат только тексты учебного репозитория, их эмбеддинги
и контрольные синтетические диалоги. Личные пользовательские диалоги остаются
в рабочем каталоге. Реальные сохранённые результаты доступны без новых вызовов.

Улучшение качества не предполагается заранее: одинаковые контрольные вопросы,
явные ожидания, отдельные примеры настройки порога, раздельные метрики поиска,
ответов и цитирования. Наличие точной цитаты не доказывает верность всех выводов.

README каждого дня содержит дословное условие, самостоятельную подробную
теорию, замысел и устройство решения, результаты и практическую пользу.
Уточнение пользователя о подробной теории имеет приоритет над ориентиром A4.
