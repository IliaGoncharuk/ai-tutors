# 0002 — Kotlin Desktop для второго задания

Статус: принято пользователем 2026-09-03.

## Контекст и решение

Для сравнения управляемого и свободного ответов пользователь выбрал Kotlin,
одновременный показ двух потоков, поясняющие комментарии и минимум кода.
Используем отдельный Compose Desktop-проект с одним `Main.kt` и отдельными
тестами. Первый челлендж не меняется.

Уточнение пользователя: модель выбирается из списка, ограничения задаются
«крутилками», а не текстом. Используем списки формата/маркера и числовые
ползунки; инструкция и локальные проверки строятся из одного снимка настроек.

## Альтернативы

- CLI: проще, но менее удобен для одновременного визуального сравнения.
- Несколько Kotlin-файлов с отдельными слоями: проще расширять, но это не
  приоритет учебного задания. Отложено по пожеланию пользователя.

## Последствия

UI и логика находятся вместе; расширяемостью сознательно жертвуем.
OkHttp SSE разбирает поток вместо собственного парсера протокола.
Coroutines доставляют события в Compose и связывают время жизни запросов с окном.
Для завершения выбрана явная инструкция, которую допускает задание.
Реальные платные вызовы при разработке требуют отдельного разрешения.
