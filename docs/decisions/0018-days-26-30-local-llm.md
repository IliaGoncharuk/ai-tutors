# 0018. Дни 26–30: самостоятельные локальные приложения

Принято пользователем 2026-10-11: выполнить все пять заданий одной
последовательной серией, каждый день в отдельной папке; использовать LM Studio;
День 27 оставить на выбор агента; в Дне 28 сравнить с облачной моделью; День 30
проверять в домашней сети.

Каждый день — отдельное приложение Node.js без общей исполняемой библиотеки.
Это сохраняет независимый запуск и ясную связь между заданием, страницей и
README. Все локальные генерации идут в LM Studio через HTTP API. Для Дня 30
Node.js слушает домашнюю сеть, но endpoint LM Studio остаётся на loopback;
внешний клиент входит в сервис по отдельному токену.

День 28 повторно использует архив текстовых фрагментов Дня 21. Их векторы были
созданы облачной embedding-моделью и не совместимы с произвольной локальной
моделью. Чтобы поиск не отправлял запрос в облако, retrieval ранжирует тексты
локально лексическим алгоритмом; прежние векторы не используются. Это меняет
метод поиска относительно исходной недели 6 и явно указано в README.

Облачная генерация Дня 28 доступна отдельной кнопкой, использует серверный
`OPENAI_API_KEY` и может быть платной. Вызовы не выполняются автоматически.
Фактический платный эксперимент не входил в подготовку приложений; отдельные
расходы требуют решения пользователя согласно правилам проекта.
