# 0005 — локальная веб-лаборатория сравнения моделей

Дата: 2026-09-05. Статус: принято пользователем.

## Контекст

Для пятого челленджа нужно сравнить три уровня моделей на одном запросе по
качеству, времени, токенам и стоимости. Пользователь выбрал веб-лабораторию
и попросил новую задачу вместо сетки из Дня 3. После обсуждения происхождения
задачи подтвердил эксперимент про подготовку научного фестиваля.

## Альтернативы

1. Node.js-скрипт и Markdown-отчёт: минимальная разработка, но менее удобная
   демонстрация нескольких ответов рядом.
2. Локальная веб-лаборатория: больше интерфейсной работы, зато наглядное
   сравнение трёх моделей и переключение повторов. Выбрана пользователем.
3. Локальные модели HuggingFace: можно измерять видеопамять, но нужны загрузка
   весов, подбор квантования и отдельная среда исполнения.

В качестве теста рассматривались планирование с ограничениями, ответ клиенту
по противоречивой переписке и поиск ошибки в коде. Выбрано планирование:
оно понятно без программирования и имеет проверяемый оптимум.

## Решение и последствия

Отдельное задание `challenges/day-05-model-comparison` использует Node.js и
локальный React/Vinext-интерфейс на основе очищенного шаблона Дня 4. Общий
исполнитель обслуживает CLI и веб. Серверный ключ остаётся в окружении.
Развёртывание внешнего сервиса не требуется.

Выбраны Luna, Terra и Sol из одного семейства OpenAI с одинаковыми настройками
и тремя повторами. Пользователь подтвердил девять платных вызовов с бюджетом
до $0,20. Сырые ответы и результаты чтения хранятся раздельно; доказательство
оптимальности не оценивается одним совпадением числа.

Задача придумана агентом для этого эксперимента, не взята из признанного
бенчмарка и не была заранее проверена на этих моделях. Перебор даёт объективный
эталон, но не обосновывает перенос результатов на все типы задач. Через API
можно сравнить расход токенов и стоимость, а не фактические GPU-ресурсы.
