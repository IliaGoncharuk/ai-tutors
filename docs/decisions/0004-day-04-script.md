# 0004. Скрипт, отчёт и локальная лаборатория для Дня 4

- Статус: принято
- Дата: 2026-09-05

## Контекст

Нужно сравнить один запрос при трёх температурах и получить проверяемые
примеры ответов. Для оценки разнообразия полезно повторить каждый вариант.

## Рассмотренные варианты

1. Три вызова, по одному на температуру: минимальные расходы, но нельзя
   сравнить повторяемость внутри настройки.
2. Девять вызовов и локальный отчёт: больше материала для сравнения без
   необходимости разрабатывать интерфейс; втрое больше вызовов.
3. Веб-лаборатория с тремя колонками: удобна для демонстрации и повторных
   экспериментов, требует дополнительной разработки.

## Решение

Пользователь подтвердил второй вариант и попросил включить условие,
справочную информацию и итоговые выводы в README. Используется Node.js-скрипт
без сторонних зависимостей, вызывающий Responses API через встроенный `fetch`.
Согласованная серия состоит из девяти вызовов. Точные условия и приёмка —
в [спецификации](../features/day-04-temperature.md).

## Последствия

Результаты можно прочитать и проверить без запуска приложения. Новый запуск
сохраняется в отдельном каталоге и расходует API-баланс. Оценка креативности
остаётся качественной, а малый размер выборки ограничивает обобщения.
Синтетический запрос и ответы пригодны для сохранения в публичном репозитории
после проверки; ключ и служебные заголовки в результаты не записываются.

## Дополнение: локальная веб-лаборатория

Позднее 2026-09-05 пользователь запросил интерфейс по образцу Дня 3 и задачу,
в которой различия температур было бы легче увидеть. Рассмотрены просмотрщик
существующих результатов и лаборатория с запуском новых серий. Пользователь
подтвердил второй вариант и ещё девять платных вызовов для мастерской снов.

Добавлен локальный React/Vinext-интерфейс в подкаталоге `web`, использующий
архитектуру и подход к компонентам Дня 3. Чистый исполнитель `core.mjs` общий
для CLI и серверного маршрута; работа с файловой системой остаётся в CLI.
Веб-маршрут передаёт результаты по мере получения, браузер хранит их в памяти
и позволяет скачать. Сохранённые серии включены в интерфейс для просмотра
без API. Публикация не запрашивалась; регистрация и развёртывание Sites не нужны.

CLI по-прежнему не требует сторонних зависимостей; веб-приложение имеет
собственный пакет и lockfile. README сохраняет первый разбор и дополняется
вторым; выводы сравнивают температуры внутри каждого сценария. Более открытая
задача не считается гарантией более сильного эффекта температуры.
