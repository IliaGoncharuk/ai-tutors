# 0019. Дни 31–35: помощники для реального проекта

Принято пользователем 2026-10-18: выполнить пять заданий последовательно за
один запуск, каждое в отдельной папке с локальным сайтом. Облачная генерация,
общий бюджет реальных проверок до $1. День 33 дан дважды, выполняется один раз.

Самостоятельные Node.js-приложения с браузерным интерфейсом, порты 3031–3035.
Независимый запуск важнее уменьшения повторения через общую библиотеку.
MCP использует SDK и настоящий stdio-процесс; выбор хостом обязательных
инструментов отделяется в описании от самостоятельного выбора моделью.

День 31 подключается к документации AI Tutors. День 32 формирует ревью diff с
поиском по документации и коду; GitHub Action сохраняет Markdown/JSON и
показывает краткий итог. Автоматические комментарии и публикация тестового PR
не входят в разрешённые внешние действия. День 33 использует синтетические
JSON-пользователей и тикеты. День 34 изменяет только учебную рабочую копию,
воспроизводимую из исходных файлов задания.

День 35 по уточнению пользователя — переносимый CLI подготовки релиза для
любого pet-проекта. Git-репозиторий и команды проверок задаются проектом.
Результаты: проверки, изменения, AI-черновик release notes и локальный отчёт;
сайт показывает тот же процесс. Проверка — на AI Tutors и отдельном тестовом
Git-репозитории. CLI ничего не публикует и не создаёт теги/коммиты.

`gpt-5.6-luna` формулирует ответы; `text-embedding-3-small` индексирует документы
в днях с RAG. SQLite хранит общий бюджет с атомарными резервами; при неизвестном
результате запроса резерв остаётся. Нет автоматических повторов. По умолчанию
данные находятся в `~/.ai-tutors/days-31-35`, в проверке — в исключённом из Git
`.local-days-31-35`. Ключ берётся только из окружения. Тексты разрешённого
корпуса, вопросы и фрагменты отправляются в OpenAI. Дополнительные встроенные
платные инструменты API не используются. Оценка расходов консервативная,
не является сверкой счёта. CI имеет собственный журнал в пределах одного
запуска; для постоянного CI ограничения аккаунта задаются отдельно.

README содержат дословные задания, самостоятельную подробную теорию, замысел
перед реализацией, результаты с происхождением чисел и практическую пользу.
Уточнение пользователя о подробности теории имеет приоритет над ориентиром A4.
Неизменённые старые README не переписываются.
