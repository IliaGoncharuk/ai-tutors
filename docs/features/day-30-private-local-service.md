# День 30 — приватный локальный сервис

Условие и объяснение: [README](../../challenges/day-30-private-local-service/README.md).

## Приёмка

- HTTP-сервис доступен на домашней сети, пока LM Studio остаётся на loopback.
- API проверяет токен доступа и ограничивает длину запроса, частоту и параллельные запросы.
- Ответы модели и задержки видны в интерфейсе; сервис выдерживает серию запросов без потери ответов.
- Проверка с другого устройства, брандмауэра и Wi-Fi не подменяется локальным тестом.
- README объясняет границы учебного LAN-сервиса и порядок остановки.
