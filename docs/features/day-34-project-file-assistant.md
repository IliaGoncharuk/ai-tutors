# День 34: операции с файлами

Условие и объяснение — [README](../../challenges/day-34-project-file-assistant/README.md).

- Сайт 3034: поиск использований API, обновление документации, восстановление
  учебной копии без модели. Источник — четыре файла sample-project.
- Модель сама выбирает MCP-инструменты. Требуется прочитать минимум три
  разных файла; до этого запись запрещена. Максимум 13 шагов генерации.
- Чтение ограничено четырьмя файлами, запись — docs/api.md рабочей копии.
  Пути и символические ссылки проверяются кодом. Исходный пример не меняется.
- После успешного обновления версия и оба маршрута соответствуют клиенту;
  повторная проверка не должна создавать новый diff. Ошибка восстанавливает
  разрешённый документ из снимка начала запуска.
- Интерфейс и протокол показывают реальные вызовы, снимки и diff.
