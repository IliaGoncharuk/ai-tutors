# День 35: переносимый CLI подготовки релиза

Исходное задание и принятые уточнения — [README](../../challenges/day-35-release-assistant/README.md).

- Самостоятельный npm-пакет `ai-pet-release`, бинарная команда `ai-release`.
  Подключение к любому локальному Git-проекту через путь или пакет .tgz.
- `init`: создать конфигурацию без перезаписи. `inspect`: чтение Git без API.
  `prepare`: локальные report.json и release-notes.md, без публикации.
- Репозиторий, base/head и включение рабочего дерева задаются CLI. Стек
  определяется командами JSON-конфигурации; проверки исполняются только при
  `--run-checks`, без shell и без передачи ключа OpenAI дочерним процессам.
- AI формулирует черновик по Git-фактам и статусам; готовность вычисляет код.
  Провал проверки/отсутствие обязательного файла — blocked; пропуск, грязное
  дерево, сокращение контекста — needs-review. Модель не может отменить ошибку.
- `--no-ai` работает без ключа и журнала API; пропуски явно указаны.
- Сайт 3035 демонстрирует тот же механизм на AI Tutors; произвольные проекты
  выбираются в CLI. Локальные отчёты не перезаписываются.
- Приёмка: реальные Git-факты AI Tutors, отдельный тестовый проект, ошибка
  проверки, работа установленной команды и воспроизводимые отчёты.

Решение и внешние границы — [ADR 0019](../decisions/0019-days-31-35-project-assistants.md).
