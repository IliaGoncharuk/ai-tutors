# День 27 — интеграция локальной LLM в приложение

Условие и описание: [README](../../challenges/day-27-local-llm-app/README.md).

## Приёмка

- Пользователь отправляет несколько связанных сообщений в отдельном локальном приложении.
- Сервер формирует контекст из истории и передаёт его только в LM Studio.
- Ответ модели и задержка отображаются в чате; историю можно сбросить.
- Поведение остаётся доступным без облачного провайдера; ошибки выключенного локального сервера показаны человеку.
