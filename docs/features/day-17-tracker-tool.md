# День 17 — первый инструмент Трекера

Условие, теория, запуск и результаты: [README](../../challenges/day-17-tracker-tool/README.md).

## Поведение и приёмка

- Названия, ключи и ссылки задач исключаются до выдачи в MCP и браузер;
  строки обозначены «Задача N». Новые результаты обезличены; правила для старых
  сохранений и границы нумерации — в [ADR 0016](../decisions/0016-tracker-anonymous-results.md).

- Самостоятельный сайт 3017 и сервер `tracker-tools`, инструмент `search_issues`.
- Параметр `period`: all / overdue / today. Только назначенные текущему пользователю
  задачи без резолюции. Дата берётся в Asia/Yekaterinburg.
- `dueDate < сегодня` — просрочка; равенство — на сегодня; отсутствие и неверная
  дата учитываются отдельно. Страницы считываются до конца, неполный ответ — ошибка.
- Модель выбирает инструмент по фиксированному пользовательскому запросу.
- Ей отправляются только семь неотрицательных целых показателей. Полные строки
  заменены обезличенными строками в таблице. Исходные результаты MCP не вставляются в контекст.
- Источник данных и режим агента независимы и явно обозначены. Смена источника
  закрывает соединение и очищает текущий результат.
- Рабочие данные вне Git; сохранение под каталогом репозитория запрещено.
- Локальный бюджет учитывает расход по токенам и резервы запросов без известного
  расхода. Ответ с корректной статистикой освобождает свой резерв. Перенос
  старого журнала и ограничения учёта описаны в README.
- Проверка: настоящий stdio, реальный API-прогон, перехват контекста в тесте,
  страницы, ошибки API, границы дат, HTTP, перенос журнала, бюджет, TypeScript и сборка.
