# День 22 — первый RAG-запрос

Условие: [README](../../challenges/day-22-first-rag/README.md#исходное-задание).
Архитектура: [ADR 0017](../decisions/0017-days-21-25-local-rag.md).

Самостоятельный сайт 3022 сравнивает plain и rag на одном вопросе, модели
и общей инструкции. Только rag получает пять найденных фрагментов. Сайт
показывает ответы, время, usage, контекст и точный запрос. Набор из 10
контрольных вопросов содержит ожидаемые факты и документы, не входящие в индекс.

Приёмка: 20 реальных ответов; отдельные метрики маркеров и смысловой разбор;
сохранённый воспроизводимый протокол; просмотр результатов без API; проверка
отсутствия корпуса в baseline и отказа от неполных ответов; типы, сборка, браузер.
