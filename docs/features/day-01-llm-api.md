# День 1: первый запрос к LLM через API

## Условие и учебная цель

Приложение должно отправить пользовательский запрос в LLM через API, получить
ответ и показать его в простом интерфейсе.

Подписка ChatGPT даёт готовый продукт для человека. API нужен, когда модель
становится частью программы или повторяемого процесса: обрабатывает данные,
работает внутри собственного интерфейса, следует фиксированным инструкциям,
возвращает результат другому коду или вызывает инструменты. Через API можно
управлять моделью, длиной, вариативностью, стоимостью и измерять один сценарий
на разных настройках. Биллинг API отделён от подписки ChatGPT.

## Принятое решение

Реализован вариант с локальным веб-интерфейсом. Причины выбора и отклонённые
варианты описаны в [решении 0001](../decisions/0001-day-01-local-web.md).

Код находится в `challenges/day-01-llm-api`:

- `app/page.tsx` — форма и отображение результата;
- `app/api/generate/route.ts` — проверка входа и серверный вызов Responses API;
- `vite.config.ts` — dev-only передача существующего `OPENAI_API_KEY` только
  серверному Cloudflare-compatible runtime; production-сборка значение не
  сериализует;
- `.env.example` — безопасный пример имени переменной без секрета.

Инструкции установки и запуска находятся в
[`challenges/day-01-llm-api/README.md`](../../challenges/day-01-llm-api/README.md).

## Поведение

1. Пользователь запускает приложение локально, без VPS.
2. В браузере он задаёт модель, инструкцию, запрос, температуру от 0 до 2 и
   предел ответа от 64 до 4096 токенов.
3. Браузер отправляет настройки только на локальный `/api/generate`.
4. Сервер валидирует модель и пределы, затем вызывает OpenAI Responses API с
   `store: false` и `reasoning.effort: none`.
5. Интерфейс показывает текст, фактические input/output/total tokens и
   справочную оценку стоимости.
6. Отсутствующий или отклонённый ключ, неверный ввод, rate limit и общий сбой
   превращаются в понятное сообщение без вывода секрета или внутренних данных.

Разрешены `gpt-5.6-luna`, `gpt-5.6-terra` и `gpt-5.6-sol`. Цены зашиты только
для учебной оценки и датированы 2026-09-02; актуальный тариф перед практическим
использованием нужно сверять с документацией OpenAI.

## Критерии приёмки

- Чистая установка запускается локально без VPS.
- Реальный запрос возвращает текст и usage-метрики модели.
- Пользователь может изменить параметры генерации до отправки.
- Ключ не попадает в браузерный код, исходники, Markdown или Git.
- Неверный ввод и ошибки API не обрушивают процесс необработанным исключением.
- README объясняет запуск, назначение API и доступные параметры.

Проверки реализации и оставшиеся вопросы находятся в текущем снимке
