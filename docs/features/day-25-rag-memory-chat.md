# День 25 — чат с поиском и памятью задачи

Условие: [README](../../challenges/day-25-rag-memory-chat/README.md#исходное-задание).
Решение: [ADR 0017](../decisions/0017-days-21-25-local-rag.md).

Сайт 3025 хранит отдельную историю и память каждой задачи: цель, ограничения,
термины и уточнения с фразой-основанием и номером сообщения. Новая задача
не удаляет предыдущую; переключение восстанавливает её состояние.

На каждый вопрос: обновление памяти, самостоятельный поисковый запрос,
новый поиск, фильтрация, ответ и проверка цитат. Модели передаются память и
последние четыре сообщения, полная история остаётся в SQLite. У каждого
принятого утверждения есть source, section/chunk_id и точная цитата.
При слабом контексте — отказ с уточнением и честно пустыми источниками.

Формы `Цель:`, `Ограничение:`, `Термин:`, `Уточнение:` и явная замена через
`Замени ограничение «…» на «…»` разбираются кодом. Дополнительные предложения
модели принимаются только с точными подстроками текущего сообщения; вопросы
с `?` отклоняются. История и память записываются вместе после успешного ответа.
Ошибка API не оставляет частичного обновления. Приложение однопользовательское.

Приёмка: два сценария по 12 сообщений пользователя, сохранение цели после
отвлечения, всех объявленных терминов и уточнений, замена старого ограничения;
свежий поиск и цитаты; независимое чтение SQLite новым процессом; локальные
тесты изоляции и ошибки API, типы, сборка и браузерный цикл задач.
Готовые реальные сценарии можно открыть в новых задачах без вызова API.
