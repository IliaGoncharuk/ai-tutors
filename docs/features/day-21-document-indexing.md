# День 21 — индексация документов

Исходное условие дословно: [README задания](../../challenges/day-21-document-indexing/README.md#исходное-задание).
Общее решение: [ADR 0017](../decisions/0017-days-21-25-local-rag.md).

Локальный сайт на 3021 показывает снимок 20 README и не менее 15 000 слов,
методику пересчёта в страницы, разбиение фиксированного размера и по структуре.
Каждый фрагмент содержит source, title, section, chunk_id и координаты.
Эмбеддинги сохраняются в SQLite и доступны после перезапуска. API-сбой во
время подготовки не заменяет предыдущий индекс частичным. Кеш учитывает
модель, размерность и точный текст. Корпус и индекс связаны SHA-256 отпечатком.

Приёмка: реальная индексация обеих стратегий, сравнение на десяти заранее
заданных вопросах, сохранённые результаты и ограничения метрики; просмотр
фрагментов и фильтрация по документу в браузере; проверки типов и сборка.
