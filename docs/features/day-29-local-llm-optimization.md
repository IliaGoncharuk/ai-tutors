# День 29 — настройка локальной LLM

Условие и самостоятельное объяснение: [README](../../challenges/day-29-local-llm-optimization/README.md).

## Приёмка

- Один и тот же вопрос можно выполнить в базовой и настроенной конфигурации.
- Сохраняются модель, температура, максимальный выход, контекст, инструкция, ответ и API-метрики.
- Качество оценивает человек по явным критериям; время и token/s берутся из API, память вводится по внешнему системному наблюдению.
- Вывод о стабильности требует повторов; квантование сравнивается только при наличии разных доступных вариантов модели.
