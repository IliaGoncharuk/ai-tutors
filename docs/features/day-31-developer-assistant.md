# День 31: ассистент разработчика

Дословное условие и теория — в [README задания](../../challenges/day-31-developer-assistant/README.md).

## Поведение и приёмка

- Самостоятельный локальный сайт, порт 3031. Вопросы начинаются с `/help `.
- Индекс: корневой README, Markdown из docs, README заданий; реальные
  эмбеддинги, источники с диапазонами строк, ручное обновление.
- MCP через stdio: реальная текущая git-ветка и список разрешённых файлов.
- Ответ использует документацию и свежий контекст; список источников и вызовов
  доступен в интерфейсе. Неверные номера цитат отклоняются.
- Контроль: структура, запуск, API-ключи, отсутствие сведений о пароле.
- Сохранённый настоящий протокол доступен без платных запросов.
