# День 28 — RAG с локальной генерацией

Условие и объяснение: [README](../../challenges/day-28-local-rag/README.md).

## Приёмка

- Используется снимок текстовых фрагментов индекса недели 6.
- Запросы ранжируют локальные фрагменты без сетевого embedding-вызова; векторы прежней модели не сравниваются с иной моделью.
- Та же выборка контекста доступна локальному и ручному облачному запуску.
- Сохраняются ответ, источники, критерии качества и задержка; стабильность не заявляется без повторов.
- Облачный запуск требует явного нажатия и серверного `OPENAI_API_KEY`; ключ отсутствует в клиентском коде.
