# День 26 — запуск локальной LLM

Условие и самостоятельное объяснение задания: [README](../../challenges/day-26-local-llm/README.md).

## Приёмка

- LM Studio показывает загруженную локальную модель и доступный HTTP API.
- Веб-лаборатория получает перечень моделей и передаёт запрос на локальный сервер.
- Не менее трёх сохранённых ответов соответствуют простому, среднему и сложному запросу.
- В протоколе сохранены модель, формулировки, ответы и задержки; живые измерения не заменяются демонстрационными данными.
