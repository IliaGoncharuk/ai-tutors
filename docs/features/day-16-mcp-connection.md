# День 16 — подключение MCP

Исходное условие и объяснение: [README задания](../../challenges/day-16-mcp-connection/README.md).

## Поведение и приёмка

- Самостоятельный сайт на порту 3016; Node.js запускает MCP-сервер через stdio.
- Кнопка подключения выполняет инициализацию и `tools/list`; карточки берутся из ответа.
- Каталог содержит `connection_info` и JSON Schema параметра `detail`.
- Обновление повторяет запрос списка; отключение завершает дочерний процесс.
- Ошибка соединения не выдаётся за успешное подключение; повторный запуск возможен.
- CLI `npm run tools` печатает реальный список и освобождает соединение.
- Ни API Трекера, ни OpenAI в этом дне не вызываются.
- Проверки: реальный stdio-процесс, схема и вызов, перезапуск, HTTP и сборка.
