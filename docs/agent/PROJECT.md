# Проект AI Tutors

## Цель

Репозиторий используется для выполнения и публикации результатов AI-челленджей
учебного курса. Каждый челлендж должен давать небольшой проверяемый артефакт и
понятное объяснение того, чему он учит и где применим на практике.

## Текущая область

- Последовательно выполнять задания курса.
- Хранить код, инструкции запуска и критерии проверки каждого результата.
- Делать решения достаточно наглядными для короткой демонстрации и рассказа.
- Не усложнять инфраструктуру без пользы для конкретного задания.

Первое подтверждённое задание описано в
[../features/day-01-llm-api.md](../features/day-01-llm-api.md).

## Термины

- **Челлендж** — отдельное учебное задание с проверяемым результатом.
- **Результат** — код и сопутствующая документация, удовлетворяющие критериям
  приёмки задания.
- **Публичный репозиторий** — репозиторий, содержимое и история которого могут
  быть доступны третьим лицам; правила безопасности приведены в
  [CONSTRAINTS.md](CONSTRAINTS.md).

## Пока не определено

Единый технологический стек для всех будущих челленджей не выбран. Стек можно
выбирать отдельно для задания, если это не создаёт ненужной сложности и
решение согласовано по процессу из `AGENTS.md`.
