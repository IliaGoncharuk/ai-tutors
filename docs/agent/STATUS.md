## Подтверждено

- Создана минимальная система проектных инструкций и документации.
- Первый челлендж реализован в `challenges/day-01-llm-api` как локальное
  веб-приложение на Node.js, React и Vinext.
- Серверный маршрут вызывает OpenAI Responses API. Ключ берётся из
  `OPENAI_API_KEY`, передаётся только серверному runtime и не попадает в
  браузерный код.
- Интерфейс позволяет менять модель, инструкцию, запрос, температуру и лимит
  ответа; после запроса показывает текст, токены и ориентировочную стоимость.
- Выбор интерфейса и рассмотренные альтернативы зафиксированы в
  [решении 0001](../decisions/0001-day-01-local-web.md).
- Production-сборка, линтер и локальная HTTP-проверка прошли. Реальный запрос
  к `gpt-5.6-luna` вернул ответ и usage-метрики.
- Отрицательный тест без ключа вернул `503`; проверка итоговых генерируемых
  файлов не нашла точного значения ключа в `dist`, `.vinext` или `.wrangler`.
- После обновления и очистки зависимостей `npm audit` сообщает 0 известных
  уязвимостей.
- Локальные файлы IntelliJ IDEA сохранены на диске, исключены через корневой
  `.gitignore` и удалены из Git index перед первым коммитом.
- Второй челлендж реализован как компактное Kotlin/JVM + Compose Desktop
  приложение в `challenges/day-02-response-control`: два ответа рядом,
  параллельный streaming, ограничения и проверки результата.
- Условия сравнения описаны в [задании 2](../features/day-02-response-control.md),
  выбор реализации — в [решении 0002](../decisions/0002-day-02-kotlin-desktop.md).
- Подготовлена [справочная статья](../guides/response-control.md) с примерами
  Kotlin и ссылками на официальную документацию.
- Для второго задания прошли `test assemble` и 12 тестов без платных вызовов,
  включая два локальных SSE-потока, отмену соединения и настраиваемые ограничения.
- Модель выбирается из списка; ограничения справа задаются списками и
  ползунками. Оценка ответа использует снимок настроек выполненного запуска.
- Обновлённое окно запущено с обычным окружением; индикатор подтвердил наличие
  ключа в процессе без проверки его действительности в API. Две колонки и
  регуляторы визуально проверены. Дальнейшая проверка кликов прервана
  пользователем через Escape; результат клика по списку модели не подтверждён.
