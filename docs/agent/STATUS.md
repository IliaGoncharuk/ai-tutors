- Создана минимальная система проектных инструкций и документации.

  ответа; после запроса показывает текст, токены и ориентировочную стоимость.

  [решении 0001](../decisions/0001-day-01-local-web.md).

## Следующие действия

1. Вручную открыть интерфейс через `npm run dev` и выбрать удобный промпт для
   демонстрации.
2. Записать короткий рассказ: подписка ChatGPT — готовый продукт, API —
   программный компонент с управлением поведением, стоимостью и интеграциями.
3. Перед публикацией проверить `git diff`, список новых файлов и отсутствие
   секретов; решение о коммите и публикации остаётся за пользователем.
