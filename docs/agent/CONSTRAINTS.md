# Ограничения и допущения

Последняя содержательная проверка: 2026-09-06.

## Подтверждённые ограничения

### Запись демонстраций

Источник: уточнение пользователя от 2026-09-05.

- Видео демонстраций пользователь всегда записывает самостоятельно.

### Завершение работы с локальными серверами

Источник: уточнение пользователя от 2026-09-06.

- После завершения работы агент останавливает запущенные им локальные
  серверы, включая фоновые процессы, и проверяет, что они больше не принимают
  соединения. Оставить сервер работающим можно по явной просьбе пользователя.

### Публичность и чувствительные данные

Источник: решение пользователя от 2026-09-02.

- Репозиторий публичный.
- API-ключи, токены, пароли, персональные данные и другие чувствительные
  сведения нельзя помещать в код, Markdown, примеры вывода, скриншоты, логи,
  Git index или историю Git.
- Приложение должно получать API-ключ из окружения во время запуска.
- Перед публикацией необходимо проверять diff, список новых файлов и вывод
  программы на случайную утечку секретов.

### Инфраструктура первого челленджа

Источник: решение пользователя от 2026-09-02.

- Для первого задания не нужно поднимать VPS или публиковать постоянно
  работающий сервис.
- Допустимы CLI или локальный веб-интерфейс.
- Интерфейс должен оставаться небольшим, но полезно показать управляемые
  параметры API, например температуру.

## Подтверждённые внешними источниками правила OpenAI API

Проверено 2026-09-02 по официальной документации OpenAI:

- Стандартное имя переменной окружения для SDK — `OPENAI_API_KEY`.
- ChatGPT и API имеют раздельные системы биллинга; подписка ChatGPT не заменяет
  оплату API.
- Responses API позволяет управлять моделью, инструкциями, ограничением длины
  ответа, температурой или `top_p`, форматом текста, инструментами и другими
  параметрами. Температуру и `top_p` обычно не следует менять одновременно.

Источники:

- <https://developers.openai.com/api/reference/cli/resources/responses/methods/create>
- <https://help.openai.com/en/articles/9039756>
