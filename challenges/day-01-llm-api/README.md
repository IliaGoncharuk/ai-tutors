# День 1 — LLM API Playground

Локальный веб-интерфейс отправляет запрос в OpenAI Responses API и показывает
ответ, фактическое число токенов и ориентировочную стоимость.

## Возможности

- выбор `gpt-5.6-luna`, `gpt-5.6-terra` или `gpt-5.6-sol`;
- системная инструкция и пользовательский запрос;
- температура от 0 до 2;
- ограничение максимального числа выходных токенов;
- безопасный серверный вызов с `store: false`;
- понятные сообщения об отсутствующем ключе, лимитах и ошибках API.

## Запуск

Требуется Node.js 22.13 или новее и переменная окружения `OPENAI_API_KEY`.

```powershell
cd challenges/day-01-llm-api
npm install
npm run dev
```

Откройте локальный адрес, который напечатает команда. Если ключ добавлен в
настройках Windows после запуска терминала, закройте терминал и откройте новый.

Проверить наличие ключа без вывода его значения можно так:

```powershell
if ($env:OPENAI_API_KEY) { 'OPENAI_API_KEY доступен' } else { 'Ключ не найден' }
```

## Безопасность

При `npm run dev` конфигурация передаёт ключ только серверному runtime, где его
читает `app/api/generate/route.ts`. Production-сборка значение не встраивает.
Не помещайте реальный ключ в исходники, документацию, браузерный код или Git.
Файл `.env.example` содержит только имя переменной и не содержит секрета.

Оценка стоимости использует тарифы OpenAI, проверенные 2026-09-02, и носит
справочный характер. Перед реальным использованием сверяйтесь с
<https://developers.openai.com/api/docs/pricing>.
