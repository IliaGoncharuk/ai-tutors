# Учебный кабинет

Небольшая учебная копия: клиент API возвращает описания запросов, экран
использует клиента для загрузки ученика и списка уроков. Сетевые запросы
не выполняются. Контракт API описан в [docs/api.md](docs/api.md).

Исходники: `src/client.mjs`, `src/dashboard.mjs`. Перед изменением документации
сопоставьте её с текущими маршрутами клиента.
