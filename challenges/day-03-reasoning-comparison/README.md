# День 3 — лаборатория рассуждений

Локальное веб-приложение отправляет одну алгоритмическую задачу в OpenAI
Responses API четырьмя способами, показывает решения рядом и формирует
Markdown-отчёт со сравнением.

## Что сравнивается

1. Прямой ответ — только условие задачи.
2. То же условие с инструкцией «Решай пошагово».
3. Модель сначала составляет решающий промпт, затем новый запрос решает задачу
   по этому промпту.
4. Аналитик, инженер и критик независимо предлагают решения в одном запросе.

Один успешный эксперимент выполняет **пять платных API-вызовов**: по одному для
первого, второго и четвёртого способов и два для метапромпта. Запросы решения
используют одну выбранную модель, одинаковый лимит, `temperature: 0.2`,
`reasoning.effort: none` и `store: false`.

## Запуск

Требуются Node.js 22.13 или новее и переменная окружения `OPENAI_API_KEY`.

```powershell
cd challenges/day-03-reasoning-comparison
npm install
npm run dev
```

Откройте локальный адрес из вывода команды. Нажатие «Запустить сравнение»
расходует API-баланс. Если ключ добавлен после запуска терминала, перезапустите
терминал или IDE.

Проверить только наличие ключа, не выводя его значение:

```powershell
if ($env:OPENAI_API_KEY) { 'OPENAI_API_KEY доступен' } else { 'Ключ не найден' }
```

## Как читается результат

Эталон `10` вычисляется локальным алгоритмом динамического программирования.
Для обычных способов проверяется последнее целое число в ответе. Для группы
экспертов отдельно проверяются строки `ОТВЕТ АНАЛИТИКА`, `ОТВЕТ ИНЖЕНЕРА` и
`ОТВЕТ КРИТИКА`. Если несколько способов получили одинаковую долю правильных
ответов, интерфейс честно показывает ничью.

Эта проверка оценивает численный итог, но не доказывает качество всего
рассуждения. Вывод относится только к текущему запуску: генеративные ответы
могут измениться при повторении. Кнопка «Скачать Markdown» сохраняет отчёт в
браузере; приложение не записывает ответы на серверный диск.

Полное условие и критерии находятся в
[спецификации](../../docs/features/day-03-reasoning-comparison.md). Решение
использует параметры Responses API из
[официальной документации OpenAI](https://developers.openai.com/api/reference/cli/resources/responses/methods/create).

## Проверки без платных вызовов

```powershell
npm test
npm run lint
npm run build
```

Тесты проверяют эталон, четыре разных промпта, извлечение ответов экспертов,
ничью и экспорт отчёта. Они не обращаются к OpenAI.

Ключ передаётся только локальному серверному runtime. Не помещайте его в код,
Markdown, скриншоты, логи или Git. Общие правила — в
[CONSTRAINTS](../../docs/agent/CONSTRAINTS.md).
