# День 2 — управление ответом на Kotlin

Desktop-приложение: один вопрос, два параллельных потоковых ответа рядом.
Весь код приложения с комментариями — в [Main.kt](src/main/kotlin/Main.kt).

## Запуск

Нужны JDK 21, интернет для первой загрузки Gradle/зависимостей и переменная
окружения `OPENAI_API_KEY`. Ключ не вставляйте в код или команду, которая
сохранится в истории терминала. Если переменная уже настроена в Windows,
перезапустите терминал/IDE, чтобы они получили новое окружение.

Из корня репозитория:

```powershell
cd challenges/day-02-response-control
.\gradlew.bat run
```

Если Java не находится, для текущего терминала можно выбрать JDK из Android Studio:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat run
```

В IntelliJ IDEA откройте этот каталог как Gradle-проект, выберите Gradle JVM 21
и запустите задачу `run`. На Linux/macOS: `sh gradlew run`.

## Демонстрация

1. Оставьте пример вопроса или введите свой неперсональный учебный запрос.
2. Выберите модель из списка. Справа задайте формат и маркер списками,
   количество пунктов, максимум слов и токенов — ползунками. Для одного абзаца
   количество пунктов недоступно. Инструкцию приложение составит само.
3. Нажмите «Сравнить»: это **два платных запроса OpenAI API**.
4. Наблюдайте за дописыванием текста в обеих колонках. Начало и скорость
   потоков могут различаться; приложение не имитирует печать готового ответа.
5. Сравните длину, формат, маркер завершения и токены. Галочки относятся к
   настройкам выполненного запуска, даже если вы уже передвинули ползунки.

Условия сравнения и точные критерии описаны в
[задании](../../docs/features/day-02-response-control.md).
Разбор теории и кода — в [справочной статье](../../docs/guides/response-control.md).

Модель по умолчанию — `gpt-5.6-luna`, как в первом задании. Доступен локальный
список моделей из первого задания; наличие модели в списке не подтверждает
доступность аккаунту. Произвольного ввода модели нет.
Автоматической смены модели, повторных запросов, экспорта или сохранения истории нет.
Закрытие окна отменяет локальные потоки; это не гарантирует отсутствия оплаты
уже выполненной сервером генерации. Правила хранения ключей — в
[CONSTRAINTS](../../docs/agent/CONSTRAINTS.md).

Индикатор «Ключ доступен в процессе» проверяет только наличие переменной,
без вывода секрета и без обращения в OpenAI. Если ключ настроен, но индикатор
говорит об отсутствии, закройте старое тестовое окно и запустите новое из
терминала с ключом. Наличие переменной в Windows не меняет окружение уже
работающего процесса.

## Проверки без платных вызовов

```powershell
.\gradlew.bat test assemble
```

Тесты используют синтетические события и локальный MockWebServer:
параметры пары запросов, текст до завершения, отказ, лимит, формат/слова/маркер,
два SSE-потока, преждевременный EOF, HTTP-ошибка и закрытие соединения при отмене.
Сетевой тайм-аут без данных — 60 секунд, общий лимит ожидания — 3 минуты.
